dsh 启动配置

沿用官方 dsh --profile 语义。运行时仍使用 HarnessDock 内置 sealed dsh，不允许设置替换可执行文件。

web / auto · 已保存

可填写自定义 profile 名称；目录对应 $DSH_HOME/profiles/<name>。HarnessDock 桌面主 Surface 还要求该 profile 最终提供 webServer + connection，以通过受管 Web-ready 检查；部分上游非 Web profile 可能不会直接产生可显示的 Harness Web。

填写时必须是绝对路径。这里只改变 profile/config 根目录，不改变内置 dsh Runtime 来源；插件隔离状态会按有效 DSH_HOME 分开，避免不同配置树互相污染。

非 web profile 在 Auto 模式失败时直接进入 Safe，不执行 web 专用插件归因，避免误隔离；Direct 用于需要保留首个 profile 启动错误的诊断场景。

这是下次启动配置；当前 Runtime generation 不会被热切换。配置在下一次 Runtime 启动或重启时生效。
