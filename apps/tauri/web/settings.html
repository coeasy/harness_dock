Web 优先启动

桌面端启动后自动启动本地 Runtime，并强制打开 Harness Web。插件诊断只在用户主动点击后出现。

Runtime 与插件恢复

第三方插件失败会被隔离；系统 Node 启动异常时自动回退内置 Node。恢复操作不会改写用户的真实 DSH 配置。刷新 Web 不会重启 Runtime；完整重启会先停止 Gateway。

checking

版本更新

检查后只安装通过签名校验的桌面更新；安装完成会先完整关闭 Runtime/Gateway，再重启客户端。

idle

点击“检查更新”后才访问 GitHub，避免启动阶段占用网络或影响 Harness Web 响应。

使用说明

正常使用只需要 Harness Web。只有需要查看 Runtime 状态、处理插件隔离或重新打开 Web 时，才使用本窗口。

on demand

插件诊断关闭后不会停止 Runtime，也不会关闭 Harness Web。停止 Runtime 是显式操作，下一次启动仍会按 Web 优先策略执行。
