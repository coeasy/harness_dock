Web 优先启动

桌面端验证安装包内置 sealed Runtime 后直接启动本地 dsh 并打开 Harness Web。插件诊断只在用户主动点击后创建。

Runtime 与插件状态

第三方插件失败可进入隔离恢复；正式产品只从安装包资源启动内置 Node+dsh，不使用系统 Node 兜底，也不会在首次启动下载另一份 Runtime。

checking

GitHub 版本检查

远程 Harness Web 不持有安装权限。v0.1.2 公共测试版以 GitHub Release 与 SHA256SUMS 交付；未配置签名发布材料时，只提供版本检查与手动下载安装，不自动安装未经签名的程序包。

manual

检测到新版本时将提供对应 GitHub Release；自动签名更新通道启用前不会静默安装。

使用说明

正常使用只需要 Harness Web。Recovery、Gateway、Diagnostics 和 Update 都是按需 Surface，不能成为健康 Harness Web 启动的前置依赖。

on demand

关闭诊断窗口不会停止 Runtime，也不会关闭 Harness Web。退出和更新检查通过 Host Protocol v2 进入统一 Reconciler/Actor 生命周期。
