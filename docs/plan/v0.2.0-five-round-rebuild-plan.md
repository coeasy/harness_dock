# 0. 一次性五轮总览

五个 Round 是五个责任域，不是五次暂停点：

```text
Round 1
Protocol + Adapter + Embedded Runtime Contract
     |
Round 2
RuntimeActor + Immutable Runtime + Process Ownership
     |
Round 3
RuntimeLease + Reconciler + Surface + Recovery
     |
Round 4
Capability + Native Gateway + Shell + CLI + Plugin
     |
Round 5
Model/Fault Tests + Performance/Size + Release Graph
```

实际执行采用一条连续链：

```text
current PR implementation branch
  -> repair compile blockers
  -> finish Round 1 contract migration
  -> finish RuntimeActor ownership migration
  -> finish Lease/Reconciler/Surface convergence
  -> finish Capability/Gateway/Shell/CLI/Plugin convergence
  -> finish verification/release gates
  -> repeat real CI repair until green
  -> final architecture audit
  -> final user-chain audit
  -> final security audit
  -> final package/runtime audit
  -> merge
  -> exact-main-SHA candidate
  -> release
```

禁止：

- “Round 1 未完成所以不能修 Round 3”；
- 为了过旧 CI 恢复已淘汰实现；
- 为了临时兼容保留两个 Runtime truth；
- 把真实失败写成“后续优化”；
- 在 current-head CI 未绿时标记五轮完成。

# 1. 统一实施规则

五轮一次性执行期间，每次改动都必须遵守以下规则：

1. **真实错误优先**：GitHub Actions / cargo / pnpm 的实际错误高于文档推测；
2. **结构正确优先于旧 gate**：旧 gate 验证旧架构时，修改 gate，不恢复旧架构；
3. **删除即迁移**：旧 ownership 被新 Actor 接管后立即删除旧 AtomicBool/sidecar/control renderer；
4. **唯一真相**：Runtime、Surface、Gateway、Update 各自只能有一个生命周期 owner；
5. **主链优先**：Harness Web 启动必须永远是第一优先级；
6. **optional fail-open**：Shell、Tray、Gateway UI、Diagnostics、Plugin UI 出错不能阻断 Harness Web；
7. **security fail-closed**：Capability、secret、origin、RuntimeLease 校验失败必须拒绝；
8. **代际安全**：所有异步结果必须能证明属于 current generation/navigation/session；
9. **无长期兼容层**：v0.2.0 直接收敛最终模型；
10. **一次统一验收**：Round 1–5 只在最后一起标记 Done。

# 3. Round 1：Protocol / Adapter / Embedded Runtime Contract 收尾

## 3.1 目标

把所有入口统一到最终 Host 边界，并把 CI/打包 contract 从旧架构升级到 v0.2.0 最终架构。

```text
Tauri Adapter
 -> Host Protocol v2
 -> Capability Broker
 -> Host Kernel
 -> Reconciler
 -> Resource Actors
```

## 3.2 必须完成

### A. Composition Root

`lib.rs` 仅负责：

- module wiring；
- AppState registration；
- command registration；
- plugin setup；
- top-level lifecycle hook。

不得继续承载 Runtime procedure、Gateway procedure、Surface procedure。

### B. Desktop Adapter

`desktop.rs` 统一承载：

- Tauri setup；
- menu event adapter；
- run event adapter；
- optional tray/update setup；
- Surface bootstrap。

### C. IPC / Host Protocol

最终只保留：

```text
HOST_PROTOCOL_VERSION = 2
HostCommand
CommandEnvelope
HostResponse
ResponseEnvelope
HostError
HostSnapshot
HostEvent
Capability
SubjectKind
RuntimePhase
RuntimeGeneration
```

所有高权限业务动作最终进入：

```text
host_execute / host_dispatch
```

Native window primitive 可保留直接路径。

### D. Embedded Runtime Contract

正式 Candidate 必须：

```text
prepare pinned upstream source packs
 -> build target runtime
 -> prune Node
 -> prune dsh production closure
 -> install/verify pinned pnpm tool
 -> generate runtime manifest
 -> integrity check
 -> startup smoke
 -> plugin-tool smoke
 -> copy into Tauri resources
 -> package
```

### E. CI Contract 升级

`check:embedded-runtime` 不再检查：

- system Node fallback；
- `runtime_starting/runtime_restarting/runtime_stopping`；
- 旧 temporary-runtime markers；
- first-run Runtime downloader。

改为检查：

- sealed bundled Runtime；
- RuntimeActor；
- RuntimeGeneration；
- RuntimeLease；
- cancellation；
- zero-download first launch；
- application resource path；
- pinned Node/dsh/pnpm identity；
- Runtime integrity + smoke。

## 3.3 Round 1 收尾退出条件

Round 1 不单独标 Done，但以下项必须在最终门禁前全部成立：

- no Electron；
- no system Node production fallback；
- no first-run Runtime download；
- Menu/Tray/Shell 不直接编排 Runtime procedure；
- CI contract 与最终架构一致。

# 4. Round 2：RuntimeActor / Immutable Runtime / Process Ownership 收尾

## 4.1 目标

让 RuntimeActor 成为唯一 Runtime owner，彻底消除旧生命周期并行真相。

## 4.2 RuntimeActor 最终状态

```text
Stopped
Preparing
Starting
Probing
Ready
Degraded
Stopping
Cancelling
Failed
```

删除：

```text
runtime_starting
runtime_restarting
runtime_stopping
```

Restart 必须生成新 desired generation，而不是设置 bool。

## 4.3 RuntimeGeneration

```text
RuntimeGeneration {
  id,
  nonce,
  image_identity,
  mode,
}
```

必须支持：

- monotonically increasing generation；
- stale generation rejection；
- restart invalidates old generation；
- start/restart/stop/cancel 状态合法性验证。

## 4.4 Runtime Process Ownership

Windows：

- Job Object；
- `KILL_ON_JOB_CLOSE`；
- child tree 跟随 Actor 生命周期。

Unix：

- process group；
- TERM -> grace -> KILL。

禁止常规路径依赖 PID 扫描。

## 4.5 Runtime Image

最终 Runtime：

```text
dsh-runtime/
  manifest.json
  LICENSE
  node.exe | bin/node
  node_modules/...
  tools/pnpm/...
```

必须保留：

- Node binary；
- Node license；
- dsh production closure；
- host target native dependencies；
- pinned pnpm plugin tool。

必须删除/裁剪：

- Node npm/npx/corepack distribution tooling；
- headers/man/docs；
- wrong OS/arch native packages；
- source maps/types/tests/examples/coverage；
- 非必要 workspace/dev closure。

## 4.6 Runtime Manifest

至少写入：

```text
clientVersion
nodeVersion
dshVersion
dshGitCommit
pnpmVersion
platform
arch
imageIdentity
runtimeSha256
buildCommit
runtimeTotalBytes
```

## 4.7 Round 2 收尾测试

至少：

- missing node；
- missing dsh entry；
- corrupt manifest；
- wrong image identity；
- crash before ready；
- invalid ready nonce；
- stale ready generation；
- cancel during start；
- stop during probing；
- repeated restart；
- process-tree cleanup。

# 5. Round 3：RuntimeLease / Reconciler / Surface / Recovery 收尾

## 5.1 RuntimeLease

最终：

```text
RuntimeLease {
  generation,
  image_identity,
  pid,
  origin,
  private_app_url,
  dsh_version,
}
```

ready handshake 必须绑定：

- current generation；
- nonce；
- owned pid；
- loopback host；
- ephemeral port；
- exact origin；
- pinned runtime identity。

## 5.2 Desired State

```text
HostDesiredState {
  app,
  runtime,
  harnessSurface,
  gateway,
  update,
  revision,
}
```

Menu/Tray/Shell/Recovery UI 只修改 desired state / intent。

## 5.3 Reconciler

Reconciler 必须：

- 幂等；
- generation-aware；
- cancellation-aware；
- quit-preemptive；
- update/restart-safe；
- 不复制 Actor ownership。

## 5.4 SurfaceActor

最终 Surface：

- HarnessSurface；
- RecoverySurface；
- DiagnosticsSurface；
- GatewaySurface；
- SplashSurface。

桌面删除永久 hidden `main` control renderer。

移动端自己的可见 `main` 不受影响。

## 5.5 Navigation Guard

Harness Web 完成加载前必须同时验证：

```text
current RuntimeLease generation
+ current navigation id
+ actual WebView URL/origin
```

stale Finished callback 直接忽略。

## 5.6 Recovery

固定顺序：

```text
normal embedded runtime
 -> plugin quarantine
 -> safe profile
 -> RecoverySurface
```

Recovery 禁止下载替代 Node/dsh。

## 5.7 Shell Fail-open

Shell 注入失败必须：

```text
restore native decoration
 -> keep Harness Web visible
 -> report diagnostics
```

不能关闭主业务 Surface。

# 6. Round 4：Capability / Native Gateway / Shell / CLI / Plugin 收尾

## 6.1 Capability Broker

授权输入：

```text
subject
surface
origin
runtime_generation
capability
```

业务 command 必须经 Broker。

### Subject 约束

`harness-web` 必须作为不可信 subject。

请求体中的 `subject` 不能覆盖真实 Tauri/WebView 来源。

## 6.2 Shell Permission 最小化

最终 Harness Shell permission 只允许：

```text
host_execute
host_snapshot
minimum required window primitives
```

不得直接暴露：

- runtime_restart；
- update_install；
- quit；
- gateway_admin；
- plugin privileged actions。

这些动作必须通过 Host Protocol + Capability Broker。

## 6.3 Protocol Codegen

建立单一 schema source，生成：

- Rust types；
- TypeScript SDK；
- capability registry；
- docs command table；
- fixtures；
- compatibility tests。

最终删除长期手写重复定义。

## 6.4 Native Gateway

正式默认 Gateway 必须为 Rust GatewayActor：

- listener ownership；
- one-time pairing ticket；
- one-time connect token；
- HttpOnly/Secure session；
- revoke；
- RuntimeLease binding；
- rate limit。

删除：

- Node Gateway sidecar；
- local bearer admin API；
- 长期固定 admin secret；
- CI 中的 sidecar build/package step。

## 6.5 Gateway Lease Invalidation

Runtime generation 改变后：

- old Gateway lease 失效；
- old connect token 失效；
- session 必须重新验证 current lease；
- stale session 不可继续代理到新 Runtime。

## 6.6 CLI

可选 `dsh` shim 指向 bundled Runtime：

```text
<resource>/dsh-runtime/node
<resource>/dsh-runtime/node_modules/@deepseek-ai/dsh/lib/bin.js
```

不复制 Runtime，不联网下载 Runtime。

## 6.7 Plugin / Profile

Host 提供管理入口：

- status/error；
- install/remove/update；
- quarantine；
- safe-mode；
- profile list/switch；
- recommended catalog。

插件管理必须使用 bundled pinned pnpm tool。

插件异常不得阻断 Harness Web。

# 7. Round 5：Verification / Performance / Size / Release 收尾

Round 5 不是“最后补几个测试”，而是证明 Round 1–4 的整个 Host Kernel 是可验证的。

## 7.1 Model / Property Tests

随机 intent sequence 至少覆盖：

- Start；
- Stop；
- Restart；
- Refresh；
- SafeMode；
- ClearQuarantine；
- Gateway enable/disable；
- Update；
- Quit。

永久不变量：

1. 最多一个 Runtime owner；
2. `Ready` 必须有 valid current lease；
3. stale generation 不影响 current actor；
4. Gateway 只能持 current lease；
5. Surface navigation 必须匹配 current generation；
6. Quit 最终没有 managed child/listener/transition；
7. first launch 没有 Node/dsh download state；
8. Shell/Tray failure 不改变 Runtime Ready truth；
9. Update Restarting 不造成 Supervisor deadlock。

## 7.2 Deterministic Fault Injection

至少：

- child crash；
- invalid nonce；
- wrong pid；
- wrong origin；
- stale ready；
- stale WebView Finished；
- Gateway bind conflict；
- stale Gateway session；
- Shell injection failure；
- updater restart race；
- tray/menu setup failure；
- packaged Runtime missing；
- manifest/hash mismatch；
- plugin crash/quarantine；
- cancellation during boot。

## 7.3 Startup Trace

最终事件：

```text
process_started
runtime_verified
runtime_spawned
runtime_ready
webview_requested
primary_visible
shell_ready | native_fallback
```

必须记录 timing，但不能记录 secret/token/private URL。

## 7.4 Performance / Size Gate

初始安装包上限：

```text
NSIS <= 150 MB
MSI <= 170 MB
DMG <= 180 MB
DEB <= 160 MB
AppImage <= 190 MB
```

Candidate 同时输出：

```text
hostBytes
frontendBytes
nodeBytes
dshBytes
pnpmToolBytes
nativeAddonBytes
integrationBytes
runtimeTotalBytes
installerBytes
prunedBytes
```

如果超过预算，必须定位到具体 layer 后再决定是否调整预算；禁止无证据放宽。

## 7.5 CI Matrix

最终 current-head 至少要求：

```text
pnpm test
pnpm check:embedded-runtime
cargo fmt --check
cargo check --locked
cargo test --locked --lib
Rust model/property/fault tests
Windows Tauri matrix
macOS Tauri matrix
Linux Tauri matrix
ci
 tauri-ci
upstream-compat
```

所有 workflow 必须验证最终架构，不得继续构建已删除的 Electron/Node Gateway/first-run Runtime downloader。

## 7.6 Release Graph

```text
verified PR head
 -> merge
 -> exact main SHA
 -> exact embedded Runtime manifest
 -> exact platform packages
 -> updater signature
 -> SHA256SUMS
 -> release tag
```

Release 前必须验证：

- tag exact SHA；
- candidate exact SHA；
- runtime manifest exact dsh pin；
- Node/dsh/pnpm identity；
- assets non-empty；
- asset immutable；
- updater version/digest/signature 一致。

# 10. 最终五遍全链路检查

在所有自动化绿灯后，再做五遍不同视角的全链路审计，而不是重复跑同一套检查。

## 第 1 遍：启动主链

检查：

- 无隐藏控制页依赖；
- 无首启 Runtime 下载；
- Shell fail-open；

## 第 2 遍：生命周期/并发

检查：

- repeated restart；
- stale generation；
- navigation race；
- update/restart race；
- quit cleanup；
- 无死锁/死循环/orphan child。

检查：

- subject 来源真实；
- origin exact；
- current lease；
- Shell 最小 permission；
- secret redaction；
- Gateway session/revoke/rate-limit；
- remote/mobile 不继承 desktop privilege。

## 第 4 遍：Plugin/Gateway/Optional Failure

检查：

- plugin crash -> quarantine；
- safe mode；
- pinned pnpm；
- Gateway bind failure；
- Tray failure；
- Shell injection failure；
- Diagnostics failure；

- wrong-platform package 无残留；
- Runtime manifest exact；
- size gate；
- package smoke；
- updater signature；
- exact SHA；
- release assets。

任意一遍发现断链，继续修复并从受影响的审计层重新验证；不能带问题合并。

# 12. 最终执行结论

从现在开始不再使用：

```text
Round 1 完成 -> 停 -> Round 2
Round 2 完成 -> 停 -> Round 3
...
```

统一改为：

```text
Round 1-5 continuous implementation
 -> continuous real-error repair
 -> continuous legacy deletion
 -> final five-round convergence audit
 -> all CI green
 -> merge
 -> exact-main-SHA candidate
 -> release
```

**五轮的最终成果必须是一套完整的 Native Host Kernel，而不是五批彼此兼容但仍保留历史分层的补丁。**

在统一完成定义全部满足以前，任何单个 Round 都不单独宣告完成；当最后一个阻断项被清除时，Round 1–5 一次性同时进入 Done。
